## 🗺️ Short-Term Learning Plan — Iterative Approach

> This plan represents my **short-term learning iterations**.  
> Each iteration focuses on one core pillar, while allowing future returns and deeper refinement when needed.

| Iteration | Core Focus | Main Objectives | Tools | Outcome |
|---------|-----------|-----------------|-------|---------|
| 🔁 **Iteration 1** | **Linear Algebra** | Build strong mathematical foundations: vectors, matrices, linear systems, geometric interpretation | GNU Octave | Conceptual mastery of linear algebra for data analysis and future machine learning |
| 🔁 **Iteration 2** | **Statistics & Probability** | Descriptive statistics, probability basics, statistical reasoning, data interpretation | Excel | Solid statistical intuition and ability to analyze real datasets |
| 🔁 **Iteration 3** | **Statistical Computing** | Apply statistics programmatically: data manipulation, visualization, modeling | R | Practical statistical analysis and reproducible workflows |

---

### 🧠 Notes
- Each iteration is **focused, not isolated**: concepts may be revisited later when required.
- Mathematical foundations are treated as **living knowledge**, not one-time checkpoints.
- This structure reflects a **realistic progression** from analysis to modeling and computation.
